# 包房战神 · macOS 使用手册

更新日期：2026 年 11 月 3 日。适用于 **0.13.0 macOS 测试版（本次重建）**。

包房战神提供两种主要用法：在“制作”中把歌曲和歌词做成视频；在“现场”中跟随 DJ 软件，为独立客屏显示歌词。现场跟随不需要逐首生成视频，实际播放与混音继续在 DJ 软件中完成。

## 1. 安装与第一次打开

本包适用于 **Apple 芯片（arm64）、macOS 15 或更高版本**。实际运行验证目前限本机 macOS 26.6.2，其他支持范围内的系统仍需验证。应用自带 Python、Qt 和 FFmpeg。

1. 双击打开 DMG，将“包房战神.app”拖到“应用程序”文件夹。收到 ZIP 时，先解压，再移动应用。
2. 双击打开包房战神。不要在压缩包预览或安装镜像内部长期运行。
3. 主窗口建议保留至少 1000 × 700 的可用空间。顶部有“现场”“制作”“曲库”；识别配置、歌曲准备与诊断在“设置与帮助”中。离开现场页时，顶部右侧的彩色状态标签持续显示当前歌词来源和客屏开关，点击即回到现场。
4. 第一次使用可先做一首已有歌词的歌曲，无需填写 API Key。

本测试包采用本地临时签名（ad-hoc），**没有 Developer ID 签名或 Apple 公证**。首次打开可能出现无法验证开发者或无法检查恶意软件的提醒。确定安装包来源可信且未被修改后，先尝试打开一次，再进入“系统设置 → 隐私与安全性”，向下找到“仍要打开”，在后续提示中确认“打开”。系统会为该应用保存例外；受单位管理的 Mac 可能不提供此选项。详见 [Apple 官方简体中文说明](https://support.apple.com/zh-cn/102445)。

如果提示“App 已损坏”或“将损坏你的电脑”，先停止打开并核对安装包完整性、重新取得可信安装包，不要把它当作普通未公证提醒处理。不要关闭系统整体安全保护。不同 Mac 的首次打开和辅助功能授权需在该机器上完成。

本包不附带用户歌曲、个人歌词库或 API Key。歌曲、图片、视频及已保存工程仍由你自己保管。升级前先按第 9 节备份。

## 2. 先做出第一首歌词视频

1. 进入“制作”，点击“选择歌曲”，选择实际使用的 MP3、WAV 等音频。
2. 点击“添加歌词”，导入与这份音频对应的 SRT、LRC 或支持的 JSON 字幕。没有歌词时，按第 4 节使用云端识别。
3. 点击播放或按空格试听。点击某句歌词可以跳到该句；点击“改词”编辑，完成后点“保存修改”。
4. 默认已配好“传统 KTV”。可在“字幕外观”换“简洁双行”，调整字号、画质，或点“字幕特效”选择其他样式与文字动画。
5. 点“保存进度”或按 **⌘S**，保存 `.bfstudio.json` 工程，方便下次继续修改。
6. 点“导出视频”，选择一个新文件位置，等待生成完成，再在原窗口点“看导出结果”检查。

导出前至少试听第一句、副歌、长句和尾句，确认歌词内容及时间与实际音频一致。强伴奏、Remix 剪辑、循环和 DJ 口播都可能影响自动识别。生成了字幕并不代表它已准确对齐人声。

“歌词走带”控制演唱时的扫色。带有效词时码的歌词按词推进；只有句时码时会提示“按句估算扫色”。这不会补造逐字时间码。换样式会保留走带开关。

需要分镜、背景素材、多轨、完整字体参数或透明 MOV 时，打开“更多编辑”。简洁页与更多编辑共用同一工程。附加音轨的完整混音应在导出结果中检查。

新识别使用云端服务。选好歌曲后点击“云端识别”，配置服务 Key，审阅上传计划和费用，再手动提交。已有 SRT、LRC 或 JSON 可以直接导入。

**保存工程和导出视频是两件事。** 修改后看到“有新修改，需重新导出”，请重新导出；“查看上次视频”仍播放修改前的成片。“制作下一首”会建立独立工程，下一首首次保存时选择新位置。

## 3. 配置一个百炼 Key

### 开通服务

打开“设置与帮助 → 百炼与识别设置”，保持默认“百炼统一配置”。

1. 点击“前往官网开通 / 充值”，在阿里云官网登录并开通百炼，按需充值。
2. 点击“获取 API Key”，在北京地域创建适用于模型调用的**通用 API Key**。套餐专属 Key 不适用于此处。
3. 将 Key 粘贴到软件的密码输入框，点击“使用这个 Key”。

官网入口：[百炼北京控制台](https://bailian.console.aliyun.com/cn-beijing/model/market) · [API Key 管理](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key) · [官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)。若软件无法打开浏览器，可复制页面显示的公共地址手动打开。付款和创建 Key 在官网完成。

默认使用 Fun-ASR 识别音频、Qwen-Plus 检查文字，接口地址和模型已预填。单首识别、A/B 盘歌曲准备、曲库批量和百炼模型文字检查共用这个 Key，通常无需打开“高级设置”。

### 是否记住 Key

| 选择 | 结果 |
| --- | --- |
| 不勾选“在这台 Mac 上安全记住 Key” | 仅本次运行使用，退出后需要重新填写。 |
| 勾选后点击“使用这个 Key” | 尝试保存到该 Mac 的系统钥匙串；先确认页面提示保存成功。 |
| 取消勾选，再点击“使用这个 Key” | 删除该主机的已保存 Key，本次运行仍可使用。 |
| 点击“清除 Key” | 清除本次运行的百炼 Key，并删除本应用保存的百炼钥匙串项。 |

应用不会把 Key 写入工程、任务回执或普通配置 JSON；已保存的 Key 也不会回填到输入框。重启后看“Key 已填入”和钥匙串状态，输入框为空不一定表示没有恢复。钥匙串锁定或保存失败时，软件会提示，不会改用明文保存。

点击“检查连接”可分别查看上传权限与文字模型的结果。文字测试可能产生少量调用费用；检查通过仍需用实际音频验证识别。处于“离线演出”时，云请求被关闭。

**本包验收边界：**安全保存与跨进程恢复的实现已通过测试凭据验证；用户真实 Key 的日常应用重启恢复尚未完成验收。首次保存后请退出再打开，检查状态；若未恢复，按页面提示重新填写，不要把 Key 发到聊天、截图或故障日志里。

## 4. 单首识别与歌词审阅

1. 在“制作”中选好歌曲，再进入“百炼与识别设置 → 语音识别”。
2. “识别哪首歌”选择“当前制作歌曲”，核对页面显示的歌名。A/B 盘入口用于已经核验的对应盘歌曲。
3. 点击“预检歌曲与上传计划”。此步骤在本机核验文件，不上传音频。
4. 核对完整文件位置、实际版本、时长、大小、服务模型和人民币费用预估。确认无误后点“确认上传并识别”。此时才上传完整音频并提交云任务。
5. 等待结果。仍在处理时使用“继续查询原任务”，保留原来的模型配置与实际音频文件。
6. 阅读识别结果，确认有时间码后点“应用识别时间轴”，回到制作页逐句试听、改词和保存。

费用预估按整个文件时长计算，实际费用以百炼账单为准。当前百炼上传入口限制为 50 MB 内、时长不超过两小时的支持格式。过大的 WAV 可以另外制作适合识别的文件，但它将成为另一个实际音频版本；不要把剪短版的歌词直接当作完整 Remix 的时间轴。

仅返回文字、缺少时间码时，可“保存参考文字”，时间轴应用保持禁用。换歌或改动歌词后，旧结果不能覆盖当前内容，应重新预检或生成建议。

若要改错字，切到“文字纠错”：

- “原版歌词匹配”无需 Key，搜索只发送歌名与歌手，匹配沿用实际音频的句时码。它适合对照文字，不会把原唱版本的时间直接套到 Remix。
- “模型文字检查”使用模型推断，只发送歌词文字，可能另行计费。对照原文和建议，逐句勾选后点“应用勾选的修改”。

## 5. 批量准备演出曲库

建议先选两首有代表性的实际歌曲走完流程，再增加曲目。

1. 在“曲库”点击“导入音频（多选）”或“导入文件夹”。等待音频身份核验完成。
2. 在“设置与帮助 → 歌曲准备”确认服务为百炼，设置可接受的“本机额度”，并检查扣除已有预留后的“剩余”金额是否足够覆盖本批新任务。
3. 勾选“允许本次手动新提交（本机额度内）”。新提交默认关闭；修改服务配置后需要重新核对计划。
4. 返回“曲库”，点击“1 生成计划”，再点“2 审阅曲目”。检查每首实际文件、已有缓存、待续查任务与新任务预估总额。
5. 关闭审阅后，点击“3 启动准备”。软件逐首处理；已经有匹配缓存的歌曲直接复用。
6. 如需停止后续任务，点“暂停”。已经受理的云任务仍保留，当前歌曲可能继续处理；暂停不代表云服务退款或取消受理。
7. 对待处理歌曲使用“继续查询”。恢复准备时复用已有缓存和任务回执。全部完成后点“核验曲库”，查看顶部“可用”“待复核”“未准备”“处理中”“失败 / 需处理”五项数量，逐首复核后再演出。

**本机额度的范围：**适用于“歌曲准备”和曲库批量的新任务预留。已有预留会累计保留，重启或换批次不会自动清零；它不是每批自动重置的预算。它也不是阿里云账户余额，不限制制作页单首识别和文字模型检查的费用。旧平台的 PTC 额度与百炼人民币额度分开计算。界面中的“已预留”不等于已核对的实际扣费。

### 重启、断网与避免重复提交

软件用实际音频版本、服务配置和本机任务回执判断是否复用。同一任务可在单首与批量入口继续查询，重启不会自动新增付费任务。

| 页面状态 | 正确处理 |
| --- | --- |
| 已有匹配缓存 | 直接复用；先检查歌词，不需要重新识别。 |
| 已有任务 ID、等待结果 | 点击“继续查询原任务”或“继续查询”。 |
| 提交状态不明、待核对 | 保留回执，到服务端核对；不要删掉记录后再次上传。 |
| 音频内容或配置发生变化 | 重新预检，核对是否确实需要新任务。 |
| 离线演出已开启 | 云端新提交和续查都停止；退出离线演出后再续查。 |

不要为“重试”删除应用数据、云任务目录或费用预留。更换模型、改变音频内容或在没有原回执的另一台 Mac 上重新识别，都可能产生新任务。歌词库备份不包含云任务回执，完整迁移见第 9 节。

本次已用一首真实歌曲验证单首和批量恢复同一份已下载结果，新增上传和识别提交均为 0。**新的真实付费识别、原生双歌曲批量和实际账单核对仍未完成验收**，不能将本地预留或复用测试视为账单已验证。

## 6. 已有歌词怎样使用

### 制作视频

选好音频后直接“添加歌词”。支持 SRT、LRC、增强 LRC 和软件支持的 JSON。核对字幕的前奏、副歌与尾句；歌名相同不代表剪辑版本相同。制作完成后可进入“更多编辑 → 导出设置”，在导出区点击 SRT、LRC 或 JSON 保存字幕。

### 供现场使用

如果已有“歌词库”备份，在“曲库 → 导入歌词库”选择备份文件夹，再导入实际音频并“核验曲库”。Serato 现场按包含扩展名的完整文件名匹配已有歌词。不同剪辑请用不同文件名。需要给当前盘新增字幕或提交识别时，在“歌曲准备”先点“核验当前音频”。

只有普通 SRT/LRC 时，可先在本机回放模式完成绑定：

1. 在曲库导入实际音频，等待核验完成。
2. 到“现场”选择“回放体验 · 无声音”。这不会启动真实 DJ 软件的播放。
3. 返回曲库，在该歌曲行点击“回放 A”，等待文件核验和载入完成。
4. 进入“设置与帮助 → 歌曲准备”，核对 DECK A 的歌曲，点“导入本地字幕”，选择相应字幕。
5. 返回曲库，点“核验曲库”，确认该实际版本已有歌词，再按下一节切到原版 rekordbox 跟随。

制作工程、视频成片和现场歌词缓存分别保存。不要只看制作预览里有字，就认为现场曲库已准备好。回放模式没有声音；听音校对请使用制作页或 DJ 软件。

## 7. 跟随原版 rekordbox：手动 A/B

本测试路线通过 macOS 辅助功能读取原版界面，不需要重签 rekordbox。当前针对 **rekordbox 7.2.19.0342、PERFORMANCE、2Deck Horizontal**，原版安装位置为“应用程序 → rekordbox 7 → rekordbox.app”。其他版本、布局、RX2 实体控制器与独立硬件播放没有因此获得兼容性保证。

### 连接与权限

1. 先完成两首歌曲的曲库准备和复核，再在原版 rekordbox 的 A、B 盘装入对应的实际文件。
2. 保持 rekordbox 双盘界面可读；在包房战神“现场”选择“rekordbox 原版跟随”，点击连接。
3. 如果提示辅助功能权限，点击软件的“辅助功能权限”入口，到“系统设置 → 隐私与安全性 → 辅助功能”，允许**包房战神-rekordbox-AX**。
4. 返回软件重新连接，确认两个盘的标题与位置更新。

发行版的命名助手随包提供，位于 `包房战神.app/Contents/Resources/app/helpers/包房战神-rekordbox-AX.app`。需要手动添加时，可在 Finder 对主应用选择“显示包内容”，按上述层级找到助手。发行版助手与开发版助手位置不同，不能假定旧授权自动适用。

只为命名助手授权即可。原版接入不要求改签 rekordbox、打开全局开发者模式或为通用 Python 扩大权限。如果系统要求认证，由 Mac 使用者完成。

### 确认歌曲并切盘

1. 点击 A 盘卡片里的“确认 A 盘歌曲”（顶部提示条在未确认时也提供同一入口），从已准备歌曲中选出 A 盘实际加载的文件。卡片显示“待确认当前歌曲”或绿色“已确认文件”。
2. 对照弹窗的 rekordbox 标题、所选完整文件位置和 Remix/剪辑版本，点击“确认 A 盘歌曲”。等文件核验完成。
3. 同样确认 B 盘。
4. 点击“指定 A 盘”或“指定 B 盘”，选择当前应显示哪一盘的歌词。原版 AX 模式目前使用手动切盘，不自动按混音推子判断人声来源。
5. 播放、暂停、跳点、变速和循环都在 rekordbox 操作，包房战神按读到的源位置更新歌词。

每次换歌后都重新确认，重新连接后也检查两盘确认状态。AX 只能读到界面标题和时间，不能读出已加载文件的精确路径；同名、同显示时长的不同剪辑尤其需要人工区分。

### 客屏内容：喊话、DJ 标识与祝福

在“现场”工具栏或右侧点“客屏内容”。内容面板在右侧展开，A/B 来源、隐藏歌词和同步入口保持可操作。

1. **喊话**：输入文字，或点欢迎、生日、感谢、返场模板；生日模板先填姓名。主预览切到“待上屏”，仅本机可见。点击“上屏 15 秒”才发布，也可选择 30 秒、60 秒或“固定显示 · 重启后保留”。回车换行，输入区内 Control+Enter 发布（Mac 实际 Control 键）。
2. **核对与撤下**：点“现场画面”看当前输出设置，点“待上屏”看草稿。顶部说明剩余时间；“撤下”立即隐藏文字，草稿保留。切换到同步或其他标签后再回来，草稿仍在。本机预览不等于电视已经收到画面；未打开客屏时会明确提示。
3. **DJ 标识**：导入 PNG、JPG 或 WebP（推荐透明 PNG），先在本机看效果，点“显示标识 / 更新标识”才上屏。隐藏保留图片，可再显示。图片最大 20MB、1600 万像素、单边 8192 像素，导入保存本机副本，移动原图不影响输出。
4. **布局**：先选“上方喊话 / 居中欢迎”或“左上角标 / 右上角标”。在“调整位置 / 外观”展开九宫格位置、大小、不透明度和字色；这些改动仍是草稿，点击发布才整体更新。预览内的歌词避让线仅在本机显示。标识在右上且客屏二维码开启时会提示避让。
5. **祝福**。选“局域网扫码”，手机和打碟电脑需接入互通的局域网。源码版配置公网服务后也可选“公网扫码”，手机可直接用流量。在“查看二维码 / 设置”取二维码或放到客屏。收到的内容由 DJ 手动上屏，每条 15 秒。喊话和祝福一次显示一条。保存失败时保留待审项，修复后可重试。[公网扫码说明](公网扫码祝福.md)
6. **全部撤下**：底部“撤下全部附加内容”一起隐藏文字、标识、祝福和二维码，保留图片、草稿、待审内容与扫码服务。它不改变歌曲的歌词来源；歌词仍用上方独立按钮控制。

“我的”提供三项复用功能：常用语可增改删（最多 20 条），正文写 `{姓名}`，使用时填姓名再预览；“历史”保留最近 10 次成功发送，点“编辑后重发”只恢复草稿，核对后再发布；“配置包”导出 Logo、布局 / 配色与常用语，换电脑导入后先预览，再点底部“采用此配置”。正式采用会替换常用语和布局、切换 Logo 并撤下现有喊话，保留本机发送历史；取消不改现场。详见 [DJ 常用语与配置](DJ常用语与配置-20261103.md)。

临时喊话到时自动撤下；即使主程序停止刷新，独立客屏仍会按保存的期限撤下。重开主程序保留上次发布的文字作为草稿及已保存图片，临时喊话 / 祝福不会自动重放。尚未发布的编辑草稿在本次打开期间保留。明确选择“固定显示”的文字及已保存标识沿用其显隐状态，客屏仍手动打开。配置保存失败时，撤下会先更新运行画面，并提示重启后核对设置；未成功保存的状态不能当作已持久保存。

这些内容用于现场输出，不写入制作页导出视频。歌词库备份与当前搬家包不包含图层，换机请另外导出 DJ 配置包。发送历史只在本机应用数据内，DJ 配置包不带历史或当前现场文字；完整应用数据备份会保留历史和素材。

### 客屏、同步微调和隐藏

- 点击“显示器设置”（窄窗口显示“屏幕”），选择输出显示器与是否全屏，再点“打开独立客屏”。在真实电视上核对文字大小、裁切与延迟；软件显示客屏已打开只说明窗口已启动。
- 选择“传统 KTV”“简洁双行”或“单行大字”。“字幕特效”可调整外观，现场入场/退场效果可单独选择。示例预演只在本机显示。
- 歌词落后人声时，使用对应盘“提前 0.1 秒”；歌词过早时用“延后 0.1 秒”。每首实际版本最多前后微调 3 秒，原始音频与歌词时码不被改写。
- 需要立即收起时，点“隐藏歌词”或按 **Control + H**。其他页面顶部也有“隐藏现场歌词”。恢复后沿用先前来源；如果连接或歌词仍未就绪，恢复不会强行显示旧词。
- 结束时点“停止跟随”，关闭客屏。它不代替 rekordbox 的暂停按钮。

客屏是包房战神的独立窗口，当前没有把歌词叠加进 rekordbox 视频窗口。原版 AX 读取时间粒度约 0.1 秒，播停与速度没有作为独立可靠字段提供；过期、空盘、未确认或没有匹配歌词时会隐藏歌词。

**排练范围：**历史两首歌曲 30 分钟实测中，9 次手动 A/B 切换未丢失确认，但仍出现过期隐藏，最长约 **0.565 秒**。当前不能称为无间隙、演出级稳定；人声同步精度、其他版本、实体控制器和场地电视仍需独立验证。正式使用前请在自己的设备完整排练，并熟悉手动隐藏。

### 开场自检与异常恢复

现场工具栏或“设置与帮助 → 开场自检”可查看打碟机、客屏、歌词显示、A/B 盘、歌单、MIDI、扫码祝福和离线演出九项。

- 自动路由不可用、推子居中无来源或指定盘未就绪时，“歌词显示”标黄并说明原因。点“查看来源”回现场右侧指定 A / B 盘；间奏暂时无字不会因此报错。
- 扫码祝福已开但二维码仍指向本机回环地址、旧网络地址，或电脑没有局域网时，清单标黄。点“检查扫码祝福”，连好包房 Wi-Fi 后关闭再打开，使用新二维码；不会自动重启服务或清空待审祝福。正常地址也需要用同一 Wi-Fi 的手机实际验证。
- 客屏意外退出按 1 / 2 / 4 秒最多自动重开三次，连续失败时可手动重新打开。主动关闭窗口、按 Esc 或等待期间点关闭会保持关闭。
- 主程序重开保留输入模式、隐藏状态、指定来源、同步微调、样式、显示器目标、歌单及固定客屏文字 / Logo 设置，重新读取当前播放位置。客屏手动打开，原版 AX 每盘歌曲重新确认；临时喊话、扫码祝福和旧播放观测不恢复。

本次重建包含上述功能，具体构建提交查看安装包附带的“构建信息.json”。清单只核对本机状态，真实电视画面、手机网络可达性与人声同步仍需现场确认。

## 8. 常见问题

| 现象 | 先检查什么 |
| --- | --- |
| 识别按钮不可用 | 是否选了歌曲、已点“使用这个 Key”、退出了离线演出，当前任务是否仍在处理。 |
| Key 输入框重启后为空 | 看“Key 已填入”和钥匙串状态；已存 Key 不会回显。若仍“尚未填写”，检查是否勾选并保存成功、钥匙串是否可用。 |
| 检查连接通过，识别却失败 | 上传权限与文字测试不等于音频识别成功；查看具体音频大小、格式、时长、服务错误和账户情况。已有任务优先续查。 |
| 批量无法开始 | 看“本机额度”“允许本次手动新提交”、计划是否已生成和审阅、文件是否还在核验、计划是否因修改配置失效。 |
| 退出、断网后不知道识别是否成功 | 保留应用数据，按原歌曲与配置继续查询；状态不明时先核对服务端，不删除回执来重做。 |
| 曲库有歌，但确认歌曲列表为空 | 该实际音频版本还没有歌词缓存。按第 5 或第 6 节准备，随后核验曲库。 |
| rekordbox 连接失败 | 核对原版版本、安装位置、双盘布局和命名助手的辅助功能权限，进入“诊断”查看具体原因。 |
| 助手权限显示开着，读取仍被拒绝 | 更新助手后系统信任可能需刷新；先停止跟随，再由使用者在辅助功能设置中移除该助手旧条目、重新添加当前助手并开启，之后重连。无需改动原版签名。 |
| 显示有连接，但客屏没有歌词 | 看是否已确认实际歌曲、指定正确盘、匹配缓存、打开独立客屏，是否手动隐藏或数据过期。 |
| A/B 切换后出现不相符歌词 | 立即隐藏，核对实际 Remix 文件和两盘确认，再重新指定。不能只凭歌名判断。 |
| 字正确，但扫色不够贴人声 | 检查是否“按句估算扫色”；整首固定偏移可微调，局部时间错误需回制作页修正时间轴。 |
| 制作页试听没问题，现场没有歌词 | 制作工程不等于现场缓存；按第 6 节为实际音频绑定并核验。 |
| 导出后看不到新修改 | 先“返回编辑预览”，保存修改，再重新导出到新文件；“查看上次视频”可能是旧成片。 |
| 云端识别无法启动 | 检查是否已配置 Key、是否处于离线演出状态，以及是否已审阅上传计划。已有字幕可以直接导入。 |

反馈问题时，提供包版本、macOS 版本、CPU 类型、所在页面、操作步骤和具体错误文字。截图先遮住 Key、私人文件位置和账户信息。云任务可保留任务 ID 供自己核对；不要公开完整回执、签名下载地址或歌曲文件。

## 9. 备份、升级和卸载

### 日常备份

在“曲库”点“备份歌词库”，选择备份文件夹。它包含歌词时间轴与版本索引，**不复制音频、Key 或云任务回执**。恢复时“导入歌词库”，再核验实际歌曲。

另外备份自己保存的 `.bfstudio.json` 工程、源音频、背景图片/视频和成片。工程引用的素材需要一并保留；只复制工程文件不能替代素材备份。

发行版的数据目录是：

```text
~/Library/Application Support/包房战神
```

在 Finder 选择“前往 → 前往文件夹”，粘贴上述位置即可打开。`~` 代表当前 Mac 用户的主文件夹。该目录保存曲库索引、歌词缓存、配置、任务回执和工作文件；Key 单独保存在系统钥匙串中。应用本体内的文件不用于存放日常数据。

未结束的云任务需要保留完整应用数据中的任务回执、结果及费用预留；不要只导出歌词库后清空旧数据。完整备份前先暂停批量、等待当前操作结束、停止现场跟随并退出应用，避免复制正在写入的数据。

### 从旧开发版迁移

新发行版与开发项目的 `runtime` 分开保存，首次启动不会自动复制旧歌曲、Key 或任务。需要保留原有工作时：

1. 退出开发版和发行版，分别完整备份开发项目的 `runtime` 和上述发行版数据目录。
2. 如果发行版尚未产生新的工作，把旧 `runtime` 的**内容**复制到发行版数据目录；不要多套一层名为 `runtime` 的文件夹。复制时保留任务回执、已下载结果及费用预留。
3. 如果两边都已有新任务或新歌词，保留两份完整备份，不直接覆盖任一侧；请由项目维护者协助合并未完成任务。只迁移已完成的歌词时，可改用“备份歌词库 / 导入歌词库”。
4. 保持原音频、工程与素材的文件位置可访问。启动发行版后先核验曲库和旧任务状态；已有任务优先在对应歌曲行点“继续查询”。迁移后，识别设置页的自动恢复入口可能不出现，不要因此删除回执或重复提交。移动或更换音频时重新核验实际版本。
5. 检查 Key 状态。普通数据目录不包含 Key；换 Mac 后需重新填写，在同一 Mac 也应确认钥匙串是否恢复成功。原版 AX 使用随发行版提供的命名助手，按第 7 节检查授权。

升级应保留原数据，退出后再替换应用。首次打开新版本，先检查曲库、Key 状态、原任务续查和客屏，再处理新歌曲。命名 AX 助手变化时，系统可能要求重新授权该助手。

### 卸载

1. 完成必要备份，暂停任务并退出应用。
2. 如果不再保留 API Key，先在软件中点“清除 Key”，确认删除成功，再退出。
3. 将“应用程序”中的包房战神移到废纸篓。删除应用本体与删除数据是不同操作；按同包数据位置说明决定是否保留数据。
4. 不再使用原版跟随时，可在系统辅助功能设置移除“包房战神-rekordbox-AX”条目。

卸载本机应用不会取消云端已受理的任务，也不会关闭阿里云账户服务。未完成任务先在服务端核对。

## 10. 常用快捷键

| 按键 | 用途 |
| --- | --- |
| ⌘S | 制作页保存工程。 |
| 空格 | 制作页播放/暂停；正在输入文字时不作为播放快捷键。 |
| Control + H | 主应用内隐藏/恢复现场歌词，不影响制作预览。 |
| Control + Option + K | 在当前现场或制作页切换歌词走带。 |

这里的 Control 指 Mac 键盘上的 **⌃ Control**，不是 ⌘ Command。快捷键在包房战神应用内生效；使用 rekordbox 时可直接通过包房战神的固定按钮接管。

## 11. 每次排练前检查

1. 实际演出音频已导入，曲库核验完成，待复核歌词已听音检查。
2. 如不需要联网识别，打开“离线演出”；识别准备阶段则关闭它。
3. 原版 rekordbox 的两盘实际文件已分别确认，指定 A/B 与当前人声来源一致。
4. 在实际输出显示器检查第一句、副歌、跳点、循环、切盘、隐藏及恢复。
5. 保存工程与歌词库备份，确认批量任务已暂停或完成，再开始正式流程。

本手册区分“功能已提供”和“真实环境已验收”。测试包适合继续排练、制作与验证；本次封装不会自动消除上述云识别验收缺口或 AX 短暂隐藏问题。
