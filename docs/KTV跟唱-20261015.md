# KTV 跟唱

日期：2026-10-15。适用：包房战神制作工作台；2026-10-21 起现场也支持相同传统 KTV 轮唱，见 [现场传统 KTV](现场传统KTV-20261021.md)。

## 怎么使用

1. 选择实际要播放的歌曲，添加对应版本的歌词。
2. 点击右侧“歌词与样式”顶部的“传统 KTV”，应用粗描边大字和黄白扫色；两行在固定的上下位置轮唱。字体、配色仍可在“字体”页调整。“简洁双行”可切回带底板样式。
3. 点击播放器“播放”，或按空格。歌曲播放时字词扫色、自动换句，下方预告下一句；不显示开唱倒计时。
4. 拖动时间轴、点击歌词定位；暂停后扫色保持在歌曲当前进度。确认效果后“导出到…”保存视频。

按钮下面标明有字词时码的句数。增强 LRC、实际识别结果及支持的逐字 JSON 可提供字词时码；按 2026-10-21 补充的走带要求，普通 SRT/LRC 在跟唱模板中也按整句区间估算扫色，界面明确注明。导入对应歌曲的真实字词时码后自动优先按词推进，无需另开效果开关。

字词时码可能是一个词组，不一定每字一个时间区间。本软件在该词的实际区间内匀速扫过文字；不会把整句长度平均分给每个字。识别结果本身的错词和时间偏差仍应按实际演唱复核。“时码”页可修改已有词区间。

## 本轮实现

- 常驻“传统 KTV”和“简洁双行”入口；同名模板调用同一预设，一次撤销可恢复。传统款应用黑体粗字、48px（480p基准）、近白／明黄扫色、3px深色描边，无字幕底板。字体和颜色仍可调整。两种样式都保留歌曲、歌词和真实时码，关闭额外动画、进出场及运动布局。
- 跟唱使用解码歌曲的源位置，40ms 查询实际播放器位置；重复位置不重绘。暂停不继续模拟时钟，回跳直接重查目标位置。
- 使用最终字体、粗体、字距和缩小字号测量整句排版，按字词边界裁切高亮。修复打字动画与高亮组合时的裁切覆盖问题。
- 当前句、下一句及间奏预告共用预览／导出绘制；去掉会在停顿时继续前进的整句装饰进度条。
- 缺失、乱序、零长度、不完整或文本不匹配的词区间安全降级；界面覆盖统计也按实际可扫色的区间计算。
- 传统款的两行使用同等字号与颜色，上行靠左、下行靠右。下一句变成当前句时保持原位，唱完的那一行替换为后续预告。长句按已有词边界／标点分为约14字的显示短句，使用原词的开始时间切换，工程与导出歌词不被改写。只有句级时码或单个超长词时不拆时间，仍整句适配。
