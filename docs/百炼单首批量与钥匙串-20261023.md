# 百炼单首、批量与安全记住 Key

## 使用

1. 在“设置与帮助 → 歌词识别设置”填写一次百炼北京地域通用 Key，点击“使用这个 Key”。默认 Fun-ASR + Qwen-Plus；单首、A/B 盘歌曲准备、曲库批量与模型文字检查共用。
2. 如需重启恢复，勾选“在这台 Mac 上安全记住 Key”再应用。默认不保存；输入框不会回显已存密钥。取消勾选并应用会删除该主机的保存项，当前会话仍可使用。点击“清除 Key”清除百炼共用内存 Key 和本应用记住的百炼钥匙串项。
3. 单首沿用预检、审阅上传计划、手动识别、审阅应用流程。批量先在“歌曲准备”设置人民币额度并开启本次手动新提交，再到“曲库”生成计划、审阅总费用、启动。暂停后允许当前歌曲完成，不派发下一首；恢复时复用已经缓存的文件。
4. 旧 302 可在独立配置入口继续使用，PTC 与人民币额度分别保存。百炼当前仅默认 Fun-ASR 有费用估算；选择没有估价的模型时，批量会说明原因并阻止提交。

## 任务与费用边界

- `AISettings` 向 `PreparationManager` 同步百炼地址、模型与同一个内存 Key；凭据按确切主机隔离，不把旧主机 Key 自动发送给新地址。
- 单首和批量按“完整音频 SHA256 + 百炼配置”使用同一 `bailian-jobs/<identity>/receipt.json`，保持已有单首回执路径兼容。批量通过 `worker.bailian_preparation` 复用现有百炼 worker、完整文件核验和真实句/词时码。
- 已知任务只查询原任务 ID；已完成结果本机复用；提交状态不明、只有预留但无回执时阻止新增提交。跨入口有文件锁，单首也会阻止重入正在处理的批量歌曲。批量上传失败或无任务 ID 的回执保留待核对，不自动反复上传。
- 批量与歌曲准备面板的费用预留先于子进程派发落盘，人民币总额用 Decimal 比较；重启和切换百炼模型/主机不清空此前人民币预留。旧 302 的预留也在切换回去时恢复。这个本机限额不代表账户余额，也不包含制作页单首调用和文字检查的费用；这些调用分别通过原有确认入口启动。
- 重新配置会使旧批量计划失效并关闭新提交开关；正在处理歌曲时要求先暂停并等待当前任务完成。重启不会自动新增付费任务。离线演出继续阻止新上传与云端续查。
- 批量结果按精确文件版本写歌词缓存，保留既有自动发布行为；歌词识别准确率仍需试听复核。不同 Remix 不按同名匹配时间轴。

## 密钥保存

通过 Apple Security.framework 的 `SecItemAdd/CopyMatching/Update/Delete` 直接读写 macOS 通用密码项，服务名 `local.baofangzhanshen.bailian-api`，账户为对应百炼主机。没有使用含 Key 的 shell 参数，也没有明文文件降级。默认本机钥匙串，不设置云同步属性；JSON 仅记录选择保存的主机和模型等非密钥信息。

启动只读取已选择记住的本应用条目；钥匙串锁定、读取被拒绝或保存/删除失败时显示明确状态，不误报成功。请求禁止弹出认证界面，避免启动时等待系统密码框；用户可解锁登录钥匙串后重试或只使用本次 Key。删除失败保留原保存状态，不能误称已忘记。后台进程使用环境白名单，Key 只进入对应任务的环境变量；状态、请求文件、工程与参数不包含 Key。

实现参考 [Apple Keychain 文档](https://developer.apple.com/documentation/security/using-the-keychain-to-manage-user-secrets)。百炼费率依据保留在预检计划内，实际计费以[官方模型价格与账单](https://help.aliyun.com/zh/model-studio/model-pricing)为准。
