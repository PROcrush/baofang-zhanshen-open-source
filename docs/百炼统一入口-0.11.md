# 百炼统一入口 0.11

2026-10-14。歌词识别和文字纠错共用一个百炼通用Key，默认北京地域 Fun-ASR 与 Qwen-Plus。

## 使用

1. 在[百炼控制台](https://bailian.console.aliyun.com/)创建北京地域的通用API Key。需要开通对应模型；套餐专属Key不用于这条识别路线。
2. 打开包房战神“设置与帮助 → 歌词识别设置”，粘贴一次Key并保存。默认 Key 仅在本次运行使用；可勾选安全记住并应用，存入 macOS 钥匙串。Key 不写入工程、任务文件或配置 JSON。
3. 可点击“检查连接”。软件获取识别模型的上传权限，并向文字模型发一条短测试文本；不会上传歌曲。两个检查分别显示结果，语音准确率仍待歌曲实测。
4. 在制作页导入实际歌曲，或选择A/B盘。先预检文件和上传计划，核对版本、时长、文件大小和人民币费用预估，再确认上传识别。
5. 服务返回后审阅歌词，再应用时间轴。切到“文字纠错”无需再填Key，逐句勾选建议后应用，句时码保留；修改文字后不沿用旧词时码。

“高级设置”可修改北京官方主机、文件识别模型和纠错模型。支持`dashscope.aliyuncs.com`旧主机及`{WorkspaceId}.cn-beijing.maas.aliyuncs.com`专属主机。不同主机的Key分别保存于本次会话，修改主机不会隐式转发原Key。其他平台通过“其他平台 / 独立配置”进入。

## 识别流程

- 本机SHA256与文件身份预检，50MB以内WAV、MP3、OGG、M4A、FLAC、AAC、WMA或MP4，单次不超过两小时。
- 通过同一个Key取得百炼临时上传策略，只允许北京地域官方存储主机、私有文件且禁止覆盖。上传表单只使用临时OSS凭证，不携带百炼Key。
- REST提交时使用`X-DashScope-Async: enable`、`X-DashScope-OssResourceResolve: enable`及`oss://`资源；明确只识别第0音轨，避免多音轨重复计费。
- 提交意向先落盘，再发送识别POST。记录任务ID；提交后超时或取消不自动重新上传提交。若前次停在上传权限阶段、尚未提交识别，修改Key后可重新预检并确认上传。后台最多20次查询，仍未完成可手动续查。
- 用原Key恢复任务；同版本同服务配置再次预检会复用原任务。完成结果下载到本机，后续恢复不再请求服务。未知提交且缺少任务ID时，需要核对百炼控制台，软件不会猜测或再次付费提交。
- 结果下载限制北京官方结果存储主机，不发送百炼Key。校验原任务ID、子任务成功、实际句/词时间码及当前文件版本，再提供审阅结果。
- 百炼临时音频有效48小时，服务结果链接有效24小时，已下载结果可本机恢复。2026-10-23 已接入串行批量准备；同一文件和配置与单首复用回执，不做高并发提交。详见[共享任务与钥匙串](百炼单首批量与钥匙串-20261023.md)。

默认Fun-ASR识别预估按整段时长乘0.00022元/秒计算，5分钟约0.066元；这是2026-10-14核对的北京公开价，优惠、实际有效语音时长和账户费用由百炼结算。模型改变时不沿用这个估算。

离线演出阻止连接测试、上传、识别和纠错，并终止本机云任务；云端已受理任务可能继续。已有本机歌词仍可使用。应用前同时校验实际音频版本及原歌词摘要，制作工程支持撤销。
