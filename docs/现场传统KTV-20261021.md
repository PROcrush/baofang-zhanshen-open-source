# 现场传统 KTV · 2026-10-21

现场字幕与制作页统一为固定双行轮唱、真实字词扫色，不显示倒计时。基线为 `7d88c12b8268fe49cd3238072c9a6a81ecc31c8a`。

## 怎么使用

1. 现场直接点击“传统 KTV”，应用黑体粗字、近白文字、明黄扫色、深色粗描边。
2. 上行靠左、下行靠右，两行同等强调。下一句开始演唱时留在原位置，唱完的另一行替换为后续待唱句。
3. 前奏和间奏预先显示待唱句，没有数字或圆点倒数。暂停保持进度，跳点直接重查当前位置。
4. 有效词区间优先驱动跟唱；按同日用户补充要求，只有句级时码时也按整句原有区间估算走带，DJ 端注明“按句估算扫色”，不制造或回写逐字时间。见 后续真实联调与走带修复。

其他直接选择为“简洁双行 / 单行大字”。传统入口会应用标准 KTV 字形配色；之后仍可修改字体、字号、普通文字/高亮颜色、描边、行距、边距、垂直位置和阴影开关。传统模式收起下一句单独颜色、对齐、渐变及预设装饰等不适用设置。

首次无设置启动默认传统 KTV。已有设置继续读取，不在加载时覆盖用户外观；点选传统入口才应用标准预设。独立客屏的背景/亮度偏好保留，实际歌曲、歌词及源时码不被改写。

## 共用实现

- `app/karaoke.py`：`traditional_lines` 只在已有词边界和标点处分显示短句；新增 `lyric_frame`，现场与制作使用相同源位置选行规则。固定行号决定上下位置，不依赖前一次播放状态，支持回跳与切来源。
- `app/lyrics.py`：传统模式将已绑定时间轴投影为当前/下一短句、固定行号与实际查询位置。只传当前需要的两行，前奏和间奏保留预显，倒计时为 0。
- `app/live_karaoke.py`：Qt Quick 的绘制组件直接使用制作页 `worker/studio_render.py` 的最终字体绘制与扫色边界。词边界通过完整字形排版测量，词间停顿不推进，不再按整行字符比例裁切传统字幕。
- `app/styles.py`：传统预设共用 `TRADITIONAL_KARAOKE_STYLE`；显式选择一次保存完整样式，沿用此前保存失败回滚和重试反馈。
- `ui/ProgramView.qml`：现场预览、独立客屏、本地透明字幕层选择同一传统组件；保留简洁双行和单行渲染分支。

静态样式示例没有来源时码，只显示传统双行外观，不伪造扫色。传统组件没有独立播放计时器；属性或实际源位置变化才请求重绘。有效字词区间、文件版本绑定、来源/时钟校验、待复核提示和隐藏状态仍沿用现场规则。
