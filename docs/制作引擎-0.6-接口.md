# 独立制作 0.6 接口与验收清单

此次所有实现均在本项目，歌暮仅作 retained REA 行为参考，不加载、复制其程序/运行资源。旧 v2 工程迁移至 v3；engineId 维持 baofang-cpu-render/v1。

## 共享数据

Studio.state.composition 为 `{version:1,fps:24,sources:{},clips:[],texts:[],audioClips:[],markers:[],concert:{}}`。时间均毫秒，布局坐标归一化 0..1。主歌曲仍 sources.audio，绝对时钟保持不变。

v3工程增加可空的 `concertDraft:{lyricDigest,composition}`，候选与已应用时间轴隔离，进入工程保存、恢复、撤销/重做。打开时核对歌词摘要、全部素材身份、其他轨和帧率一致。`state.concertHasDraft` 区分候选编辑和已应用片段；已应用片段由普通分镜界面修改。

composition.sources 键为 sourceId，值 `{identity:<app.studio.file_identity>,kind:'video'|'image'|'audio',durationMs:<number>,width:<int>,height:<int>}`；图片 durationMs=0。片段 `{id,sourceId,kind:'video'|'image'|'color',startMs,durationMs,sourceInMs,rate,fit:'cover'|'contain',locked,color,transition:{id,durationMs}}`。color 片段 sourceId=''，color='#RRGGBB'。转场是该片段开头与前一片段尾部的混合，画面时间线片段不重叠，只在首段之后且邻接边界可使用，长度不能超过两边段长的一半。默认 cut/0。视频源 sourceInMs+durationMs*rate 不超过源 durationMs，速率 .25..4。

独立文字 `{id,startMs,durationMs,text,x,y,fontSize,fontFamily,fontBold,color,opacity,layoutId,animationId,locked}`，fontSize 基准480p，布局与动画用自研目录。音轨 `{id,sourceId,startMs,durationMs,sourceInMs,rate,gain,locked}`，gain=0..2；主音频不变，附加轨实际混合。markers `{id,positionMs,label}`。concert 保存 `{sourceId,sourceSegments:<seconds model>,targetDigest,pairing:<candidate data>,reviewed:<bool>,coverage:<stats>}`。

app.composition 提供 empty_composition(), validate_composition(value,duration_ms,identity_validator=None), make_clip(source_id,kind,start_ms,duration_ms,**options), make_text(text,start_ms,duration_ms,**options), edit_clip(composition,clip_id,changes,duration_ms), split_clip(composition,clip_id,position_ms,duration_ms), remove_clip(composition,clip_id,duration_ms), generate_storyboard(composition,segments,duration_ms,source_ids=None,default_transition='cut'), build_concert_composition(composition,source_id,source_segments,target_segments,duration_ms,gap_source_id='',reviewed=False)。所有编辑纯函数返回新数据，校验失败不改变原数据。支持 source validator 回调，没有循环导入 app.studio。

worker.style_catalog 导出 TEMPLATES,EFFECTS,LAYOUTS,TRANSITIONS,TEXT_LAYOUTS（均 id/label/description，布局包含参数）。worker.studio_render.draw_frame(segments,settings,position_ms,background=None,composition=None,transparent=False) 保持老签名兼容。worker.composition_render.CompositionSampler(composition,width,height,fps=24,duration_ms=None) 提供 frame(position_ms) 与 close()，输出背景QImage（素材/转场）；preview/export传入真实主歌曲duration_ms，不以分镜末端猜时钟。渲染 request 增加 composition/outputFormat，renderer 核验所有 source paths，附加声音混合与字幕/文字共同导出；不依赖 app 控制器。

settings 原有 fontSize/fontFamily/templateId/effectId/width/height，新增 layoutId/textColor/highlightColor/strokeColor/strokeWidth/shadow/fontBold/letterSpacing/lineSpacing/x/y/entranceId/exitId/fadeMs/backgroundColor/bpm/fps。默认 layoutId='standard', x=.5,y=.78,fps24,bpm120；老设置缺省时填充默认值。颜色#RRGGBB，坐标0..1，fadeMs0..2000，stroke0..12，间距0..20，行距.8..2，bpm40..240。

- updateSegmentTiming(int index,float startMs,float endMs)；splitSegment(int index,float positionMs,int textIndex)；mergeSegment(int index)；updateCharacterTiming(int segmentIndex,int charIndex,float startMs,float endMs)；exportSubtitles(str format) / exportSubtitles(str format,str path)。

Studio state composition/materialSources/transitions/layouts/textLayouts/outputFormat/concertRows/concertCoverage/waveform/beatsMs 必须可见，edit校验和undo由父控制器统一负责，busy禁止编辑。

## 验收

目录：15个自有模板、8个字幕效果、184个参数化布局、53个方向/形态转场（实际独立实现，有些共享算法，不能称184种不同算法）；逐项绘制，验证有效并多时刻变化。视频：合成音视频、至少3分镜+转场+文字+附加音轨，时间线变速/裁剪位置实际解码核验。演唱会：歌词候选、未匹配补镜、人工确认、改速/裁剪、完整背景影片+主曲字幕导出，核验覆盖、源身份、可撤销及重开。UI真实操作全部重要入口，1000/1440窗口，异常/取消不发布错误结果。不得把候选匹配宣称真实歌唱同步验证。
