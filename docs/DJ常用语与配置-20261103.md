# DJ 常用语、发送历史与配置包

2026-11-03。当前源码功能，尚未重新制作应用安装包。入口：“现场 → 客屏内容 → 我的”。

## 操作

- **常用语**：新增、编辑、删除，最多 20 条；标题 1–16 字、正文最多 300 字。`{姓名}` 是可填写变量。保存只保存模板；回到“喊话”点常用语、填姓名、看待上屏预览，再发布。常用入口先显示前四条，其余在“更多常用语”选择。可从当前草稿点“存为常用语”。
- **历史**：最近 10 次成功发布的喊话及已审核祝福，仅在本机保存。点“编辑后重发”恢复内容、原布局和常用时长到草稿，核对或改名后再次发布；点击历史本身不会重放，也不会撤下当前内容。
- **配置包**：导出 `.bfdj.zip`，包含 Logo 副本、当前草稿的布局 / 配色及常用语。排除当前现场文字、发送历史、歌曲、Key、网络与显示器地址。姓名等内容若被自己明确保存为常用语正文，会作为常用语一同导出。
- **导入**：先读取包并在主预览查看标识，不改变当前画面或常用语。可取消并保留原草稿。明确“采用此配置”后，一次替换常用语 / 布局、切换为包内标识并撤下当前喊话；没有 Logo 的包会隐藏原标识。本机发送历史保留。采用和取消固定在面板底部。

常用语和历史随应用数据重启恢复；它们不会在启动时自动发布。临时喊话与已审核祝福仍按原有期限撤下。应用安装包继续暂缓重建。

## 实现与边界

- `app/screen_library.py`：常用语及历史校验，窄范围 ZIP 配置包。`screen-layers.json` 升级为 schema 2，布局、常用语和历史在同一文件中原子保存，兼容读入 schema 1。保存历史或常用语时保留当前运行态对应的持久显隐，避免复活已撤下内容。
- `app/controller.py`：发布成功后才记录；历史存盘失败提示“已上屏，请勿重复发送”，不把已成功发送误报为失败。个人词库作为控制台集合排除出客屏 IPC 快照。采用配置失败保持旧配置和画面；常用语 / 布局的正式采用只做一次原子写入。
- `ui/ScreenPersonalPanel.qml`：词库编辑、历史复用和配置导入导出；主 `ScreenContentPanel.qml` 负责变量填写和待上屏预览。词库按内容缓存，心跳刷新不反复销毁常用语按钮。
- ZIP 只接受 `profile.json` 与可选 `logo.png`，拒绝未知路径、重复条目、加密、过大文件、错误版本或散列不符；不按归档路径解压。Logo 沿用受限的 Qt 图片解码和本机副本流程。包最大 24MB、Logo 20MB；图片仍限制 1600 万像素 / 单边 8192。
- 完整应用数据备份含历史。歌词库备份和现有搬家包仍不含这份个人配置，换机另外导出 DJ 配置包即可携带所需布局 / Logo / 常用语；历史有意不随 DJ 配置包传递。
