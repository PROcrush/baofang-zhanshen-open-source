# 制作模板更新 · 2026-10-15

制作模板改为更轻的排版，并修复切换模板时沿用上一款粗描边、字号和动画的问题。简洁制作界面预览旁的“字幕特效”直接展开效果图和文字动画，无需进入时间轴。

本项目实际渲染的16款模板

## 选择与使用

- 跟唱：传统 KTV、简洁跟唱，按导入时码扫色和换句；依照 2026-10-21 用户要求已取消全部倒计时。
- 清爽：留白双行、电影字幕、左下歌签、顶部轻题、现场大屏，减少遮挡，适合背景视频。
- 设计：封面大字、薄荷夜场、短句海报、对唱分屏、竖排留白、杂志封面、强调字卡、柔光焦点、轻动标题。

打开“字幕特效”先显示全部16款，也可按推荐或分类筛选。简洁界面使用较大的效果图，点选即应用。“文字动画”页直接选择7种动效或无额外动画；返回歌词后仍可调整文字大小和视频画质。时长、布局参数和入离场动画放在更多编辑中。

全部模板可通过“歌词走带”开关跟唱扫色；有效词时码优先，其余按原句时间估算，不生成逐字时间。关闭走带时，薄荷夜场保留固定双色排版。轻动标题使用短促上浮入场，读取歌曲时间，因此暂停、拖动和导出一致。制作动态动画的入口和时长修复见特效字幕排查。

## 修复内容

1. 每款模板带完整字形、配色、描边和基础动画预设。选中时一次应用，撤销一次恢复；继续调整仍可自定义。
2. 移除旧模板的通用进度装饰、彩边框、侧边粗线、斜切底板和重色光环。强调字卡的底色贴合文字宽度，柔光焦点只保留柔和的可读性遮罩。
3. 模板缩略图与主预览使用同一个预设函数和绘制引擎，避免缩略图是轻字体，应用后却继承 KTV 粗描边。
4. 现代标题优先按现有标点分行。长句保留全部文字，根据空间缩小；极长的单句达到最小字号后再收紧横向宽度，避免超出画面。歌词内容与原始时间不改写。
5. 保留原16个模板ID，原工程可以继续打开。只有主动选择模板时才应用完整预设，不在打开工程时重设用户配色。传统 KTV 的固定上下两行、黄白扫色和字体规则保留。
