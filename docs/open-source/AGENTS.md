# Contributor instructions

- Read `README.md`, `PRODUCT.md`, and `DESIGN.md` before changing behavior or UI.
- Preserve the 1000×700 desktop workflow, manual A/B takeover, local preview before publishing, and explicit cloud-submission consent.
- Use temporary runtimes and synthetic media for tests. Do not operate real DJ applications, change macOS permissions, upload media, or make paid API calls as part of routine checks.
- Keep music, model weights, API keys, cloud receipts, screenshots with private data, build products, and local diagnostics out of Git.
- Distinguish unit / simulated / source UI checks from real DJ, MIDI, and television acceptance. Do not claim unsupported compatibility.
- Keep changes scoped, preserve existing user edits, and run the checks appropriate to the change.
- Original contributions use the repository's MIT license; preserve third-party notices.
