# 歌词走带开关

用户需要一个直接可见的按键，让各种字幕都能出现 KTV 跟唱扫色效果。本轮将走带独立于外观选择，现场与制作都可一键开关，不增加专业参数或倒计时。

## 使用

- 现场：预览右上方“歌词走带”。覆盖 27 个现场预设，以及传统 KTV、简洁双行、单行大字。现场预览、独立客屏和 Serato 透明层同步生效。
- 制作：简洁界面“字幕外观”旁的“歌词走带”；更多编辑的歌词检查器也有同名开关。覆盖全部 16 个歌词模板，包括叠排、分屏、竖排及多行长句。预览和新导出共用设置。
- 当前现场或制作页按 Ctrl+Alt+K 快速切换，macOS 使用实际 Control 键。按钮选中表示开启，关闭后仍按时间自动换句。鼠标、键盘和辅助功能切换采用相同实际状态。
- 换模板、现场配色及单双行保留开关。开启时若高亮色与底色太近，自动使用可辨认的黄色或青色。

## 时间与保存

优先使用已有有效词区间，长音继续、词间暂停。仅有句时码时按原句起止估算扫色，操作端显示“按句估算扫色”；时码质量仍为句级，不生成逐字数据。所有进度由源播放位置查询，暂停保持、跳点重算，失效和隐藏规则继续生效。无时码的静态示例不代表真实跟唱。

制作的换行与竖排仅映射源文字游标，预告句保持未唱颜色，独立添加的标题文字不参与歌词扫色。现场开关自动保存，写入失败回滚并显示错误。制作开关支持撤销、工程保存和重新打开；旧工程没有该字段时延续原行为，跟唱模板开启、其他模板关闭，打开不改写文件。新工程默认开启。

- 实际 QML 控件在 1000×700 和 1440×900 检查按钮与快捷键；三条现场输出路径开启/关闭扫色，全部现场预设画面随源位置推进。27 个样式卡片和 88 套配色实际点击、保存重载检查通过。长句、换行和中英文混排使用字形遮罩，推进时不重排文字。
- 简洁制作完整流程通过实际本地合成音频与 MP4 导出，包含简洁/更多编辑按钮及辅助功能切换；共享样式像素检查、现场细调、496 字长句与来源过期清空检查通过。最终 QML 警告为 0。
- 本机证据位于忽略的 `runtime/lyric-sweep-20261021/`。共享旧工具的图片继续写入其既有 runtime 目录，本轮日志集中留在新目录。合成检查不替代真实 Serato、实际人声对齐或包房电视验收。
