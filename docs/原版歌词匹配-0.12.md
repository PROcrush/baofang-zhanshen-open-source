# 原版歌词匹配 0.12

文字纠错默认进入“原版歌词匹配”。流程为实际歌曲识别 → 自动查找参考歌词 → 文字和拼音锚点匹配 → 审阅修改 → 保留实际时间码应用。独立实现，运行不读取歌暮应用、代码或资源。

## 使用

1. 在制作页打开实际音频及其识别歌词，进入“模型 API / 文字纠错”。
2. 原版歌名从文件名提取，去掉Remix后缀；可填写原唱歌手缩小范围。
3. 点击“自动找歌词并匹配”。优先匿名查询网易云音乐，无可用歌词时尝试LRCLIB。只发送歌名与歌手，无需额外API Key，不发送音频、识别歌词、时间码或百炼凭据。
4. 有明确歌名和足够文字覆盖时自动生成建议。重名或版本相近时选择歌手和来源，点击“用这版匹配”。任何修改均需审阅后应用。
5. 列表显示原文、建议、参考句及时间码处理方式。短片段、截断尾字、重复采样、无锚点片段保留识别原文；不自动补唱、补漏字或修改DJ口播。
6. 同字数替换保持句和字词时间边界；增删字建议默认不勾选，保留实际句时间边界并清除尚未对齐的字词位置。原始识别字词及来源摘要保存于本机审阅记录。
7. 制作页支持撤销。切歌、改词或音频内容变化后，旧建议不能覆盖当前内容。参考缓存按歌名和歌手保存、校验歌词摘要；离线只使用可用缓存。

“模型文字检查”为可选次级功能，仍使用百炼Qwen或其他兼容模型。其建议来自模型推断，并未搜索原版歌词，界面明确标注来源。

## 匹配边界

每个原版连续1–3句形成文字窗口；等价的重复副歌去重。按实际识别句优先匹配整句，再匹配标点分隔的片段，允许Remix重复、删段及重排。同音字用拼音辅助，高相似度和候选差距共同控制建议；截断文字只作为片段锚点，不自动扩为完整原版句。没有重做声学对齐，文字匹配百分比不是听音准确率。

两个公开歌词源均可能超时、无歌词或返回错误内容。读取有大小和时间限制，失败保留原文，可改歌名或使用已有缓存。来源歌词也可能有错，审阅与试听仍必要。LRCLIB目前仅通过模拟备用契约验证，本机实际访问超时；网易云实际检索已通过。

## 2026-10-14 实际歌曲验证

测试复用《流星雨又来临(BlackSamurai.T黑武士 Remix)#.wav》先前百炼Fun-ASR返回的真实时间轴；238.571秒，14句、101个字词时间段，绑定音频SHA256。不新增百炼调用或音频上传。

网易云检索找到魏晨版本（歌曲ID156008），文字覆盖76.8%，10/14句找到锚点，生成1处同音错字建议。原版歌词未支持此前模型猜测的新增字；截断句和DJ口播保留。14句、101字词时间边界逐项校验完全相同。该结果只证明检索、匹配与时码保留；未证明所有歌词听音准确、声学对齐或包房客屏输出。
