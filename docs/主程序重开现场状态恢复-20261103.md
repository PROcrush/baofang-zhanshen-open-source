# 主程序重开现场状态恢复

日期：2026-11-03（Asia/Shanghai）。基线 `0e485bf`，分支 `codex/karaoke-handoff-20261102`。

## 操作行为

此前只有样式、同步微调、显示器目标、输出类型、对唱设置和歌单会持久保存；主程序重开总从回放演示与自动选盘开始。现在输入模式、歌词来源、隐藏前的来源也会在操作时立即原子保存，强制结束后仍可恢复最近一次成功写入的选择。

- 隐藏后重开仍隐藏；点击原有“恢复歌词”或 Ctrl+H 回到隐藏前的自动 / A / B 来源。
- 直接启动保存的 Serato / rekordbox 读取器，等待新观测；启动时先发布空播放快照，覆盖上次 `program.json`。正常关闭与强制结束采用同一恢复方式。此前点击“停止跟随”的输入模式也会在重开时重新接入。
- `--serato`、`--rekordbox`、`--rekordbox-ax` 优先于保存模式，直接启动指定接入，仍保留隐藏与选盘。原版 AX 中不适用的“自动”转为 A 盘；隐藏状态保持。
- 播放位置、旧观测、文件核验凭据、AX 歌曲绑定和临时插字重新建立。原版 AX 每盘重新确认实际文件；新观测未到或歌词未就绪时，恢复来源也不会强制显示歌词。
- 客屏沿用上次目标和类型，由 DJ 手动打开；rekordbox 模式使用独立客屏。原有客屏子进程限次重开机制继续适用。
- 保存失败仍立即执行隐藏或人工接管，并显示“现场状态未保存：下次启动可能恢复旧设置”。再次点击会重试，成功后清除提示。
- 缺少或损坏记录时采用回放演示默认值；旧版 `settings.json`、制作工程和歌词格式保持兼容。

## 保存与代码

`app/live_settings.py` 负责会话读取、保存和输入模式文案，`Controller` 在启动、切模式与选来源时应用；`app/main.py` 在构造控制器前解析指定模式，避免先起合成回放再切到现场。

新 `runtime/live-session.json` 只含 `schemaVersion=1`、`inputMode`、`selectedSource`、`resumeSource`，使用已有原子写入及 fsync；启动读取限制 4KB。该文件属于本机运行记录，不放进 Git 或搬家包。其他持久设置仍由原模块负责。
