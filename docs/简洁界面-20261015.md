# 简洁制作界面 · 2026-10-15

用户希望软件简单上手，制作时能直接看到跟唱效果。默认界面现在围绕选歌、添加歌词、试听、导出四个动作，专业设置通过“更多编辑”进入。

## 使用方法

1. 点击“选择歌曲”，或从欢迎页继续最近工程。
2. 点击“添加歌词”导入字幕；没有文件可点“自动识别歌词”，进入原有识别、费用预检与结果审阅流程。
3. 点击“播放”或按空格试听，拖动进度条或点击右侧歌词定位。点“改词”直接修改当前句，再保存修改。
4. 根据需要选择传统 KTV / 简洁双行、标准 / 大字 / 特大、标准 / 高清 / 超清；背景可直接更换。
5. 点击“导出视频”选择新文件，等待生成并自动保存，在原预览区播放检查。“返回编辑预览”继续调整。

新工程已配好传统 KTV 字体、明黄扫色和深色描边。只有句级时间的字幕自动换句；有效字词时间才能扫色。切换视图不修改原工程内容；已有工程的字体、配色、模板、时码和素材身份继续保留。主动点击样式按钮才应用对应预设。

“工程”菜单包含打开、另存一份与最近工程；已有工程的“保存进度”直接写回当前文件。完整模板、动画、字形参数、分镜、演唱会对齐、多轨时间轴和输出格式都在“更多编辑”，可随时返回简洁界面。

主导航只保留现场、制作、曲库。歌曲准备、现场字幕样式、歌词识别设置、诊断和素材工具统一在“设置与帮助”。本轮调整制作页与全局入口，现场等页面的内部布局保持既有实现。

## 实现

- `ui/StudioSimplePanel.qml`：双栏布局、原位改词、播放、保存及直接导出。右栏仅显示两个样式和字号、画质三个常用选择，主预览始终可见。
- `ui/StudioPanel.qml`：两种视图共用控制器、源时钟和工程；隐藏视图不创建第二个成片播放器，避免重复出声。
- `app/studio.py`：新建工程使用现有传统 KTV 预设；打开工程沿用已存设置。
- `ui/Main.qml`：精简主导航，配置入口按需展开。
- `tools/check_studio_simple_ui.py`：本机合成音频和背景的完整新手操作流程，包含真正的 MP4 导出、解码帧及播放器时钟检查。
