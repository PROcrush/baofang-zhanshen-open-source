## 包房战神接口与保存规则

`Controller.stylePresets` 提供本地卡片、中文分类、配色数据与方案 0 的完整预览样式。`setStylePresetScheme(id, index)` 应用指定配色；新 ID 为 `jizura-<原 id>`，原四个快捷 ID 保持不变。方案没有原始命名，因此界面按顺序显示“配色 1”等。

颜色映射为 `fg → baseColor`、`accent → highlightColor`、`sub → nextColor`、`bg → backgroundColor`、`accent2 → decorationColor`；带 `grad` 的方案使用两端颜色绘制文字渐变。纸感方案以其背景色描边并关闭投影，其他方案保留适量描边与投影。按原字体种类使用系统 PingFang SC 或 Songti SC，字号、间距、单双行和位置均可继续修改。应用预设保留现场亮度及倒数开关；新预设启用独立客屏背景，Serato 透明字幕路径仍须保持整屏透明。

旧八字段样式可迁移。预设身份、方案索引、装饰枚举、颜色与开关经过严格校验，未知字段不透传。用户微调保留原预设 ID，标记“已微调”，方便继续切换配色；切换配色重新应用该方案。设置通过临时文件原子替换写入，保存失败恢复原样式。原四个快捷预设会清除新增装饰及渐变，避免上一个预设效果串入。
