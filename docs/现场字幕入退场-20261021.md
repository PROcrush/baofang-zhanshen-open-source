# 现场字幕入退场

2026-10-21，根据用户确认，将歌暮现场菜单观察中建议的四款常用效果接入包房战神。绘制为本项目独立实现，不调用或复制参考程序、字体、图片和动画资源。

## 怎么用

1. 现场预览右上方点击“字幕特效”。
2. 预览下分别选择“入场效果”和“退场效果”，各有无、柔和叠化、涟漪波纹、色差分离、数字故障。
3. 选择后自动在本机演示；点击“预演效果”可再看一次，“跟随现场歌词”返回现场。示例不上客屏，不播放声音。

两项默认均为无。时长自动适配，不需要调参数。选择效果不会更改歌词走带、外观、歌词时间码或歌曲文件；切换27组样式、配色和三种行布局保留效果。保存失败回滚该次选择，在原位提示，重试成功后清除。

## 实际渲染规则

| 效果 | 独立绘制方式 |
| --- | --- |
| 柔和叠化 | 平滑透明度变化 |
| 涟漪波纹 | 文字横向分带波形位移，并渐显/渐隐 |
| 色差分离 | 按文字透明遮罩生成双色分离轮廓，收合到原字形或散开 |
| 数字故障 | 源时间决定的离散切片错位，并渐显/渐隐 |

传统KTV的上下两行保持固定上左/下右轮唱。每句首次预显时入场，结束前退场；待唱句变为当前句时不重播入场、不换位置。当前句退场不影响下一句的字形与位置。前两句首次显示位置为源时间0；旧当前句结束后，新预告句进入腾出的行。

简洁双行和单行大字使用相同文字合成器，按当前句原有起止时间入退场，预告句保持静态。外观的底板和背景保留原用途，四款效果作用于歌词文字。旧静态示例没有源时码时不擅自启动动画。

实际时钟始终来自扣除同步偏移后的歌词查询位置，效果不使用独立墙钟或随机数。默认单侧窗口为源时间300ms，上限为该句显示区间的四分之一，两端不重叠。暂停、变速、跳点直接重查，重复访问同一位置得到同一画面。手动隐藏、来源过期或停止接入立即隐藏全部歌词，不排队播放旧句退场。走带继续优先真实词时码；句时码仍只估算扫色，不修改原数据。
