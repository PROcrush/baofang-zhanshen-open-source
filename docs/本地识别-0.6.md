# 独立本地语音识别 0.6

识别代码为本项目的 `worker/studio_transcribe.py`，后端使用 OpenAI 公开发布的 `openai-whisper==20250625`，以 CPU 运行。普通 FFmpeg 解码音频，模型明确来自用户选择的普通 `.pt` 文件或本项目 `assets/models/tiny.pt`。不使用其他应用包的工具、模型或资源。

官方依据：[Whisper 仓库](https://github.com/openai/whisper)、[模型地址与摘要表](https://github.com/openai/whisper/blob/main/whisper/__init__.py)、[词级对齐实现](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)。词级时码来自模型交叉注意力与动态时间规整的对齐结果，属于估计，需要人工复核；不是已核验的演唱同步。

## 安装与模型

在项目的虚拟环境中安装可选依赖：

```sh
.venv/bin/python -m ensurepip
.venv/bin/python -m pip --isolated install --index-url https://pypi.org/simple -r requirements-local-asr.txt
```

本轮已从 OpenAI 官方公开地址获取多语言 tiny 模型：

```text
https://openaipublic.azureedge.net/main/whisper/models/65147644a518d12f04e32d6f3b26facc3f8dd46e5390956a9424a650c0ce22b9/tiny.pt
```

项目位置 `assets/models/tiny.pt`；文件大小 75,572,083 bytes；SHA256 `65147644a518d12f04e32d6f3b26facc3f8dd46e5390956a9424a650c0ce22b9`。每次按 tiny 名称加载均核对该摘要。识别过程中仅加载已有本地文件，不下载模型、不调用云识别。

## 固定命令合同

```sh
.venv/bin/python worker/studio_transcribe.py --request /absolute/path/request.json
```

请求最多64 KiB，重复字段、非有限数值和未知字段会拒绝：

```json
{
  "audioPath": "/absolute/path/song.wav",
  "durationMs": 42000,
  "model": "tiny",
  "output": "/absolute/path/new-transcription.json"
}
```

`audioPath`、`durationMs`、`output` 必需。`model` 可省略，默认 tiny；另外可用 `modelPath` 指定明确选择的普通绝对 `.pt` 路径，禁止应用包内部资源。`language` 可选，默认 `zh`，可设 Whisper 语言代码或 `null` 自动判断。结果只能保存到已存在目录中的新 `.json` 文件，已有文件或符号链接不会覆盖。支持最大24小时音频，最多10,000个字幕段落。

标准输出为逐行 JSON 事件；其他模型日志送标准错误：

```json
{"type":"progress","value":0.5,"message":"已识别 1 个本地音频窗口"}
{"type":"done","timelinePath":"/absolute/path/new-transcription.json","receipt":{}}
{"type":"error","message":"具体错误"}
{"type":"cancelled","message":"本地识别已取消"}
```

成功退出0、错误退出2、取消退出130。支持 SIGINT/SIGTERM；CPU 原生计算可能在当前调用返回时才处理 Python 信号，控制器可在短暂等待后终止工作进程。取消检查在源摘要、每个窗口前后、结果发布前后执行，临时文件自动清理，失败不发 done。

输出是可直接交给 `app.studio.from_recognition` 的秒模型：

```json
{
  "schema": "baofang-subtitles/v1",
  "segments": [
    {"start":0.2,"end":2.7,"text":"你好世界。","characters":[
      {"start":0.2,"end":1.2,"text":"你好"},
      {"start":1.5,"end":2.7,"text":"世界。"}
    ]}
  ],
  "receipt": {}
}
```

兼容键 `characters` 储存的是模型实际返回的词段，可能含多个汉字，不能称每一个汉字都已获得单独声学时码。不会按句长或字数平均分配。零时长、越界、重叠或文本不一致的词时码整句舍弃，保留句级稿并在回执中计数。输出 `start/end` 是源歌曲绝对秒时钟。

回执包含 `engineId/sourcePath/sourceSHA256/model/modelPath/modelSHA256/package/packageVersion/device/alignmentHeadPreset`、实际 `durationMs/windowSeconds/windows/segmentCount/wordTimedSegments`、`actualWordTiming/allSegmentsWordTimed/timingGranularity/characterTimingSynthesized/discardedInvalidWordTimingSegments/manualReviewRequired/networkUsedDuringRecognition`。源文件读取前后核对 SHA256，变化时拒绝发布。`characterTimingSynthesized=false`，`manualReviewRequired=true`。已核验 tiny 使用官方包附带的 tiny 对齐 head mask；其他本地模型使用模型默认 mask。

## 分窗与验证边界

每次只解码最多30秒、16kHz单声道 float32 PCM（最多480,000个样本），窗口结果加实际 offset 后映射回原曲。不会把完整歌曲 PCM 一次放进内存；字幕行数有界。窗口之间不传模型文本提示；30秒切点可能切断词或乐句，需要编辑复核。tiny适合功能闭环与短片识别，歌曲、人声伴奏和方言的准确率需由实际素材确认。

可注入 `backend(samples,language)`、`decoder(path,start,duration)`、`probe(path)` 与取消/事件回调进行边界测试。`tests/test_studio_transcribe.py` 验证分窗偏移、保留实际词段、句级回退、NaN/错误请求、取消、不覆盖目标文件、竞争发布、源变化和暂存清理。真实中文语音及依赖安装验证结果见文末执行记录。
