# 歌词时间轴 v1

开发版只接受用户导入的本地 JSON，不上传音频。先导入音频核验 SHA256，再将该版本 ID 写进歌词；歌名不参与绑定。

```json
{
  "schemaVersion": 1,
  "versionId": "sha256:实际音频文件的64位摘要",
  "durationMs": 120000,
  "quality": "sentence",
  "segments": [
    {"text": "一行歌词", "startMs": 2000, "endMs": 7000}
  ]
}
```

源时码单位为毫秒，片段递增且不重叠。句级不生成估算字级扫色。

`quality=word` 时，每句含 `words` 数组：每个元素为 `text,startMs,endMs`，文本拼接须完全等于句文本，字时码递增、不重叠、处于句范围内。导入通过只证明结构和文件绑定，不能证明声学时码准确。

当前只有 WAV 时长由解码元数据核验；其余格式仅建立文件身份，尚不可载入位置回放。内置 `demo:A/B` 是无音频的合成样例，不是用户音乐版本。
